1. What Was Built

A production-grade, fintech-grade crowdfunding platform — not a CRUD scaffold. Three channels of secure authentication, a compliance-backed (KYC) campaign system, a complete Razorpay payment pipeline with bank-grade concurrency controls, a governed admin panel, rich community features, and an AI assistant.

Functional Scope

Auth (email/Google/OTP)6-step campaign wizardKYC DonationsRefundsSettlements ~25 admin modulesBlogsEvents VolunteersNGOsJobsAI chatbot

Engineering Depth

  • Idempotent payments (locks + DB triggers)
  • 5% platform-fee split, reconciled at settlement
  • Dual-approval campaign activation (KYC + admin)
  • 18 security controls, defense-in-depth
  • ~50-model relational schema, 90+ migrations

4. Database & Data Model (Summary)

~50 Eloquent models across 6 domains, backed by 90+ migrations with indexes, foreign keys, soft deletes, and a money-integrity DB trigger.

DomainKey Models
IdentityUser, KycVerification, FundraiserLevel, UserFundraiserLevel
CampaignsCampaign (state machine), CampaignProduct, CampaignUpdate, CampaignLog, Category
MoneyDonation, DonationItem, Refund, Coupon, CouponRedemption, CampaignSettlement, SettlementItem
ContentBlog + polymorphic Comment/Like/View/Report, Tag, Event, EventRegistration
CommunityVolunteer/Application/Assignment, Organization/Application, Partnership, Celebrity, JobPost/Application
CommsSubscriber, ContactMessage, Notification, GiftCard, Faq, LegalPage, SuccessStory
Money integrity: raised_amount is derived by a MariaDB trigger from summed completed donations — the single source of truth. Every donation stores total/original/discount/fee/net for full auditability.

5. Scalability & DevOps

Strengths (built-in)

  • Stateless money logic (triggers + locks) → safe horizontal scaling
  • Indexed hot queries; cache locks; queue-ready mail
  • REST API scaffold for mobile/SPA
  • 5 scheduled commands (expire, KYC reminders, WebP, UUIDs, metrics)

Roadmap (scale-up)

  • Redis cache/session driver; queue workers (SQS/Redis)
  • Unique DB constraint on gateway_refund_id
  • Object storage (S3) for media/KYC
  • Sanctum API auth + rate limiting; metrics/alerting
